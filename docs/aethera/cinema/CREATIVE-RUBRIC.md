# Rubrica Criativa e Pesos do Ensemble

Pesos do `EnsembleScorecard` (`evaluateEnsemble`):
- **Técnico / Segurança / Direitos:** `30%`
- **Visual / Tipografia / Safe Zones:** `22%`
- **Áudio / Loudness / Stems:** `22%`
- **Narrativa / Ritmo:** `16%`
- **Comédia / Entretenimento:** `10%`

Regra de independência: o avaliador não pode incluir `producerRole` (`director_agent`), garantindo revisão separada antes dos Release Gates.
