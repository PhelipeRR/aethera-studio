# Brand fonts

Embedded in the channel identity pieces (SVG/PNG) generated by the Velix Canal tab.
All are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows embedding and
redistribution in a product. Files come from the @fontsource packages (Latin subset).

- Inter (Rasmus Andersson) — 600, 900
- Anton (Vernon Adams)
- Archivo Black (Omnibus-Type)
- Bebas Neue (Dharma Type)
- Instrument Serif (Instrument)
- Space Grotesk (Florian Karsten) — 700
- Fredoka (Milena Brandão, Hafontia) — 700
- JetBrains Mono (JetBrains) — 700

Regenerate `packages/shared/src/brand-fonts.generated.ts` with `node scripts/generate-brand-fonts.mjs` after changing these files.
