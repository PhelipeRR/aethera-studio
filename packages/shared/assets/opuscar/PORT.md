# Lemo-opuscar ports

NeuralBridge carries a small, frozen native port of the approved first batch:
Swiss Motion Graphics, Whiteboard Explainer, Data Storytelling, Dark Tech
Keynote, Caption News and Halftone Dossier.

The port contains only data presets and the app's own Remotion implementation.
It does not run the upstream CLI, install packages, download guides, update
itself, execute shell scripts, or make network requests at render time.

Upstream: `lemomo-ai/lemo-opuscar` (MIT), resolved read-only on 2026-11-04 to
commit `bebbbe1aa92a3cb4bb6f83500e61b23a17d1aa00`. Attribution is shown by the
style gallery and stored in the style registry. The frozen port remains local;
the hash is provenance evidence, not a runtime dependency.
